## About the Internship

The Cisco Virtual Internship Program provided practical exposure to networking and cybersecurity concepts. The program focused on developing an understanding of cybersecurity fundamentals, network infrastructure, security controls, common cyber threats, and methods used to protect systems and networks.

As part of the internship, I also worked with Cisco Packet Tracer to understand and simulate network environments. The learning program covered topics ranging from basic cybersecurity and networking to firewall technologies, access control, cloud security, cryptography, security monitoring, risk management, and incident response.

## Objectives

The main objectives of the internship were:

* To understand the fundamentals of cybersecurity.
* To learn about common cybersecurity threats, vulnerabilities, and attack vectors.
* To understand network infrastructure, including routers, switches, and TCP/IP.
* To study network security mechanisms such as firewalls and VPNs.
* To understand access control and authentication concepts.
* To identify common threats such as malware, phishing, ransomware, and social engineering.
* To learn the basics of security monitoring and threat detection.
* To understand vulnerability assessment and risk management.
* To gain knowledge of cloud security and cryptography.
* To understand the fundamentals of digital forensics and incident response.
* To design and simulate networks using Cisco Packet Tracer.

## Week-wise Curriculum

| Week   | Module                               | Description                                                                                                                       |
| ------ | ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| Week 1 | Cybersecurity Basics & Packet Tracer | Threats, vulnerabilities, network security fundamentals, Packet Tracer installation, and basic networking                         |
| Week 2 | Network Attacks & Infrastructure     | Attack techniques, wireless security, network devices, and security infrastructure                                                |
| Week 3 | Windows, Linux & Endpoint Security   | Operating systems, endpoint protection, security principles, and checkpoint assessment                                            |
| Week 4 | Defense Mechanisms & Access Control  | Network defense, access control concepts, branch office networking, and monitoring using Packet Tracer                            |
| Week 5 | Firewall & Access Control Security   | ACLs, firewall technologies, zone-based firewalls, and network defense concepts                                                   |
| Week 6 | Cloud Security & Cryptography        | Cloud security principles, encryption techniques, cryptographic applications, and security assessments                            |
| Week 7 | Security Monitoring & Alert Analysis | Network protocols, security data analysis, threat detection, and security alert evaluation                                        |
| Week 8 | Risk Management & Incident Response  | Governance, compliance, vulnerability assessment, threat intelligence, digital forensics, incident response, and final evaluation |

The curriculum covered eight weeks of structured learning and practical cybersecurity concepts.
